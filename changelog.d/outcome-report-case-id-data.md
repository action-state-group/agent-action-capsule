- **ts:** the outcome-report model no longer parses a benchmark pipeline's conversation-id layout (`benchmark:domain:<model>:task-N:trial-T`). With the reports withheld, a case record matches a conversation when it declares `urn:<conversation id>`, or when its own disclosed input states the case fields (`case.benchmark`, `domain`, `task_id`, `trial`, `agent_model`) that produce the conversation id and the action id it declares. A model-named id whose case input is not disclosed no longer resolves from the id alone (action-state-group/agent-action-capsule#343).
