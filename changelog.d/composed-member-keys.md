- Evidence Bundle -03 `composed/v1` member keys (#663): under `controller_binding` and `same_key`, a member Bundle's key comes from its root record's verified producer signature or, for a root record with neither `signature` nor `key_id`, from the Bundle's checkpoint signer when the record's identity and its own membership under that checkpoint hold, at the checkpoint's time. A present signature that fails never falls back, and a key is never read from a value the record states, so `controller_binding`'s `pointer` is optional and, when present, must select that key. Every such join reports each member's key source (`record_signature`, `log_checkpoint`, `history` or `none`). A block that -02 rules linked through a key its root record merely names becomes `not_derivable`. Python, Go, TypeScript and Rust implement it; `vectors/bundle/composed-key-source/` (17 cases) pins it, and the `controller_binding` and History vectors gain the reported key sources.
